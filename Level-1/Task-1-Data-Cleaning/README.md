## Task 1: Data Cleaning & Preprocessing

## Overview

This project was completed as part of the Codveda Technology Data Analytics Internship; Level 1.

The objective was to inspect, clean, and preprocess a sentiment dataset to prepare it for further analysis.

## Dataset

The dataset contains social-media sentiment data, including engagement metrics and timestamp information.

After preprocessing, the dataset contained:

 > 710 rows
 > 13 columns
 > 0 missing values
 > 0 duplicate records

## Data Cleaning & Preprocessing

The following steps were performed:

 > Inspected the dataset structure and dimensions.
 > Checked data types.
 > Checked for missing values.
 > Checked for duplicate records.
 > Identified and handled data-quality issues.
 > Converted the timestamp information into useful temporal features.
 > Prepared the cleaned dataset for exploratory analysis.

## Tools Used

 > Python
 > Pandas
 > Jupyter Notebook
